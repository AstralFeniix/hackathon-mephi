# Результаты тестирования приложения.

В качестве результатов тестирования взяты результаты из демо-видео приложения.

## Характеристики используемого аудио-файла:

- Обработка аудио-файла происходела около 6 минут.
- Файл весит 365 Кб
- Длина аудио-файла 45 секунд
- Диалог между 2мя людьми

## Характеристики тестируемого устройства:

- Процессор MediaTek
- Архитектура arm64
- 8 ядер
- ARM Neon
- 8 Гб оперативной памяти
- Renderer Mali-G52
- Vulkan 1.3.0
